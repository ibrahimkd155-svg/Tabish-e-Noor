# Tabish-e-Noor Private High School

## Files
- `index.html` — language selection and school branding
- `branches.html` — three branch cards
- `branch.html` — branch detail template
- `admin.html` — visual admin-page preview only
- `style.css` — blue-and-white responsive styling
- `app.js` — language switching and page interactions
- `logo.jpeg` — official logo supplied by the school

## Deployment
Keep all files in the repository root (the same folder as `index.html`) and redeploy on Vercel. The filename must remain exactly `logo.jpeg`.

## Important
The admin page is not a functioning content-management system. Secure login and a database/backend are required before it can manage live school content.
