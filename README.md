# Tabish-e-Noor School Website — Starter

This is a responsive, multilingual static front-end starter for the Tabish-e-Noor school website.

## Included
- `index.html`: language selection (Dari, Pashto, English)
- `branches.html`: three separate branch cards
- `branch.html`: branch information page; branch ID is passed in the URL
- `admin.html`: admin-panel concept/preview only
- `assets/css/style.css`: responsive blue-and-white styling
- `assets/js/app.js`: language switching and basic navigation

## Run locally
Open `index.html` in a browser, or deploy the folder to GitHub + Vercel.

## Important limitations
- The branch details, contact details, manager profile, real photos, news and gallery are placeholders and must be replaced with school-approved information.
- `admin.html` is only a visual preview. It is NOT a secure admin panel and does not save or publish content.
- Before real admin use, add a backend/database, secure authentication, role-based permissions for each branch, and safe image upload/storage.
- The logo is currently a text placeholder (`TN`); replace it with the official logo when supplied.
- All three languages have starter UI translations. Real school content must also be translated and reviewed in all three languages.
