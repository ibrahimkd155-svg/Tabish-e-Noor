# وب‌سایت لیسه عالی خصوصی تابش نور

این نسخه، پنل مدیریت را با ساختار دیتابیسی که قبلاً در پروژه Supabase ساخته شده هماهنگ می‌کند. طراحی عمومی سایت و فایل `style.css` حفظ شده است.

## فایل‌ها
- `index.html` و `branches.html`: صفحه عمومی با یک شعبه واقعی
- `branch.html` و `branch-content.js`: نمایش معلومات مکتب، خبرها و گالری
- `secure-admin/index.html` و `admin.js`: پنل خصوصی مدیریت
- `supabase-config.js`: آدرس پروژه و کلید عمومی Supabase
- `schema.sql`: فقط سیاست تکمیلی لازم برای درج/ویرایش معلومات شعبه؛ این فایل دیتابیس را حذف یا بازسازی نمی‌کند.

## راه‌اندازی
1. در Supabase، فایل `schema.sql` را در SQL Editor اجرا کنید. این فایل فقط دسترسی مدیر مجاز برای درج و ویرایش رکورد جدول `branches` را تکمیل می‌کند.
2. همه فایل‌های این بسته را در ریشه پروژه GitHub بارگذاری و Deploy کنید؛ ساختار پوشه `secure-admin` باید حفظ شود.
3. پس از Deploy، آدرس `https://tabishnoor.vercel.app/secure-admin/` را باز کرده و با ایمیل و رمز حساب مدیر وارد شوید.

## امنیت
- ثبت‌نام عمومی باید خاموش بماند.
- پنل از تابع دیتابیسی `is_school_admin()` استفاده می‌کند تا ایمیل واردشده در `admin_allowlist` بررسی شود.
- کلید Secret یا Service Role هرگز نباید در فایل‌های سایت قرار گیرد.
- مسیر پنل در صفحات عمومی لینک نشده و صفحه ورود دارای `noindex,nofollow` است؛ امنیت واقعی را احراز هویت و RLS فراهم می‌کند.

## ساختار مورد انتظار دیتابیس فعلی
`admin_allowlist`, `branches`, `announcements`, `gallery_items`, `school_settings` و باکت Storage به نام `school-media`.

این بسته برای ساختار قبلی شامل `admin_users`, `news` و `gallery` نیست؛ فایل SQL قدیمی آن ساختار نباید اجرا شود.
