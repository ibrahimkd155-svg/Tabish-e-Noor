# وب‌سایت لیسه عالی خصوصی تابش نور

این بسته نسخهٔ آمادهٔ اتصال به Supabase است. ظاهر و ساختار صفحات عمومی حفظ شده و مسیر پنل مدیریت در `secure-admin/` قرار دارد؛ هیچ لینک عمومی به پنل اضافه نشده است.

## ورود مدیر
- ورود پنل با ایمیل و رمز عبور Supabase انجام می‌شود.
- ثبت‌نام عمومی باید در Supabase خاموش بماند.
- حساب مدیر اصلی در فایل `schema.sql` با UUID حسابی که کاربر در Auth ساخته، به جدول `admin_users` اضافه می‌شود.
- دسترسی‌های دیتابیس با Row Level Security کنترل می‌شوند.

## تنظیم
1. در Supabase بخش SQL Editor را باز کنید.
2. تمام محتوای `schema.sql` را اجرا کنید.
3. فایل‌های این بسته را در ریشهٔ پروژهٔ GitHub جایگزین کنید و در Vercel Deploy بگیرید.
4. پس از Deploy مسیر `/secure-admin/` را باز کرده و با ایمیل و رمز عبور مدیر وارد شوید.

فایل `supabase-config.js` شامل Project URL و Publishable key عمومی است. هرگز Secret key یا service_role را در فایل‌های مرورگر قرار ندهید.
