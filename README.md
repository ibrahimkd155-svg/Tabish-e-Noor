# Tabish-e-Noor School Website — fixed starter

This is a static HTML/CSS/JavaScript starter designed for GitHub + Vercel.

## Important file placement
Keep these files together in the repository root:
- `index.html`
- `branches.html`
- `branch.html`
- `admin.html`
- `style.css`
- `app.js`

Do not put `style.css` or `app.js` inside folders unless you also update the paths in every HTML file.

## Deploy
Push/commit all files to GitHub. Vercel should redeploy automatically if the project is connected to this repository. You can also redeploy the latest commit from the Vercel Deployments page.

## Notes
- The first page lets visitors choose Dari, Pashto, or English.
- The selected language is stored in the browser and reused on the following pages.
- Three branch cards link to separate branch views using `branch.html?id=1`, `branch.html?id=2`, and `branch.html?id=3`.
- School details, images, contact information, and manager information are placeholders.
- `admin.html` is a visual preview only. It is not a real secure content management system and does not publish or save website content.
