# وب‌سایت لیسه عالی خصوصی تابش نور
نسخه آماده برای پنل مدیریت و Google Search Console. فایل‌های `index.html`، `branches.html`، `branch.html`، `style.css`، `app.js` و `logo.jpeg` حفظ شده‌اند؛ پنل مدیریت با Supabase کار می‌کند.

ابتدا `SETUP-راهنما.txt` را بخوانید و `schema.sql` را در Supabase اجرا کنید. سپس آدرس پروژه و anon key را در `supabase-config.js` وارد کنید. فایل تأیید گوگل، `robots.txt` و `sitemap.xml` در ریشه پروژه قرار دارند.
